Welcome to the Gaming Webstore

What is this website?

The Gaming Webstore is a cloud-based platform designed to help you discover, compare, and purchase games across all platforms.

How do we do this?

By integrating data from popular platforms such as Steam and Epic Games, the system provides personalized game recommendations based on your existing library and recent searches.

This prototype demonstrates cloud application development using Flask, Google Cloud services, SQL and NoSQL databases/
